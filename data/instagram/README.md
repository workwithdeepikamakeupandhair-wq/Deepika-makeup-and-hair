# Instagram export goes here

Unzip the Instagram data export (JSON format) into this folder, then run `npm run db:ingest`.

How to download it (done by the account owner, @deepikamakeupandhair):

1. Instagram app → **Settings** → **Accounts Center** → **Your information and permissions** → **Download your information**
2. Pick the Instagram account → **Some of your information**
3. Tick **Content** (posts, reels) and **Personal information** only
4. **Download to device** → Format: **JSON** → Media quality: **Low** → Date range: **All time**
5. Instagram emails a link when it's ready (minutes to a few hours). Download the zip and unzip it here.

Only post/reel captions and the public profile (name, bio, website) are used.
Everything in this folder except this README is git-ignored.
